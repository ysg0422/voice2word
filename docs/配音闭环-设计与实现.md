# 配音闭环：设计与实现

> 状态：已实现（2026-10-23）。代码：`subtitle::dub`（时间轴规划）、
> `engines::tts::synthesize_batch`（批量合成）、`core::dub_flow`（编排）、
> 「统计与导出 → 配音」卡、CLI `--dub`。未做的部分见文末第 9 节。
> 目标：把「译文/原文 → 逐句 TTS → 按字幕时间轴对齐 → 混音或替换音轨 → 出片」
> 做成一条可在界面与 CLI 里直接跑完的闭环。

---

## 1. 为什么做这个

2026 年同类工具（pyVideoTrans 19.5k★、SmartSub 5.8k★、YouDub 5.7k★、SoniTranslate、
Auto-Synced-Translated-Dubs）的**共同标配**就是「翻译 + 配音 + 烧录」。本项目在
字幕编辑、质检、工程导出（剪映/FCPXML/Premiere）上更强，但缺配音这一整块。

## 2. 现状盘点（可复用的积木）

| 能力 | 位置 | 说明 |
|---|---|---|
| TTS 合成 | `tools/edge_tts_runner.py` | 支持 `--text/--voice/--rate/--pitch/--volume/--output`，以及 **`--batch-json`**（每项可带 voice/rate/pitch/volume/output，逐项 `[PROGRESS] i/n` 写 stdout） |
| TTS 引擎封装 | `src/engines/tts.rs` | `synthesize_sentence`（有界等待 60s+字数、可取消、双端抽干、Python 环境清洗） |
| 音轨替换/混音 | `src/engines/ffmpeg.rs::replace_video_audio` | `bgm_volume=0` 纯替换（`-c:v copy` 极速）；`>0` 混音（`amix` + 原声按比例压低） |
| 解码 | `ffmpeg.rs::decode_pcm_mono(path, rate)` | 任意媒体 → 单声道 s16le PCM（内存） |
| 写盘 | `subtitle::audio_prep::write_wav_mono16` | PCM → WAV |
| 字幕模型 | `subtitle::Segment` | `start/end`（秒）、`display_text()`、`translation`、`speaker` |
| 说话人 | `engines::diarization` | 已能给每句打 `speaker` 标签 |

**缺的只有中间那段**：批量合成 → 时长测量 → 速率自适应 → 时间轴放置/混音。

## 3. 数据流

```
segments（含译文/原文、说话人、时间轴）
   │  ① 选文本：译文优先（source=translation）或原文（source=text）
   ▼
DubItem[]：{ index, text, voice, rate_percent=0, output=tmp/seg_N.mp3 }
   │  ② 批量合成（一次 python 进程，--batch-json）
   ▼
seg_N.mp3 × N
   │  ③ 逐个解码为 24kHz 单声道 PCM，测时长
   ▼
时长 vs 时间窗 [start, end]
   │  ④ 超窗且可由速率补偿 → 第二遍批量合成（rate = ceil((自然时长/窗宽-1)*100)，封顶 max_rate_percent）
   ▼
DubPlacement[]：{ start_sample, len_samples, seg_index, trimmed }
   │  ⑤ 混入整轨缓冲（重叠处相加并做软限幅），长度 = 媒体时长
   ▼
dub.wav（24kHz 单声道）
   │  ⑥ replace_video_audio(video, dub.wav, out, bgm_volume)
   ▼
out.mp4
```

## 4. 关键算法与取舍

### 4.1 文本选择与说话人音色

- 文本：`translation` 非空且 `source=translation` 时用译文，否则用 `display_text()`；
  空文本句直接跳过（不出空音频）。
- 音色：按 `Segment::speaker` 轮换预设音色，避免全片一个声音：
  `voices = PRESET_VOICES 里语言匹配的项`（zh / en，按目标语言或句 `language` 判定），
  `voice = voices[speaker.unwrap_or(0) % voices.len()]`。
  用户可在配置里覆盖 zh/en 的首选音色（`[dub] voice_zh / voice_en`）。
- **不做**声音克隆（需要 F5-TTS/CosyVoice/VoxCPM 等重模型），留作后续可选后端；
  先把「多角色轮换 + 时间轴对齐」这条主线跑通。

### 4.2 速率自适应（为什么两遍合成而不是拉伸）

字幕时间窗是硬约束：一段 1.8s 的字幕塞 3.2s 的配音，必须压缩。两条路：

1. **音频时间拉伸**（atempo/WSOLA）——保音高，但实现复杂，且过度拉伸会有金属音；
2. **让 TTS 本身说快一点**（Edge-TTS `--rate=+N%`）——音高与音色自然，代价是多一次网络合成。

选 2，理由：Edge-TTS 的 rate 是原生参数，质量最好；且只需要对「超窗的那部分句子」
重合成一次（通常占比不高）。规则：

```
natural = 自然语速时长（秒）
window  = end - start
如果 natural <= window * 1.02        → 不需要重合成
否则 required = ceil((natural / window - 1) * 100)
     if required <= max_rate_percent → 第二遍以 +required% 重合成
     else                            → 以 +max_rate_percent% 重合成（尽力而为）
```

`max_rate_percent` 默认 35：再快就听不清了，宁可让这一句轻微溢出到下一句前的空隙里
（见 4.3 的放置规则），也不把语音压成机关枪。

### 4.3 放置、溢出与截断

- 每句放在 `round(start * rate)` 处；
- 若某句 PCM 超出 `end`，**允许溢出**到下一句开始之前（自然语流里句间本就该连读）；
- 但若会**压到下一句的起点**，在下一句起点前 30ms 做线性淡出并截断
  （避免两个人同时说话听不清主次）；
- 音轨总长 = 媒体时长（`total_duration`，未知时取字幕终点）；末尾不足补静音；
- 混音时重叠样本相加，用 `i16` 饱和（`clamp`），不做归一化——配音轨本身电平已由
  Edge-TTS 控制，归一化会让句子间音量忽大忽小。

### 4.4 与背景音的关系

`bgm_volume`（0~1）：

- `0.0` → 纯替换：原音轨整条丢弃，`-c:v copy` 不重编码视频，秒级出片；
- `>0` → 混音：原音轨按该比例压低后与配音轨 `amix`。
  **注意**：这是简单压电平，不是真正的 sidechain ducking（按配音能量动态压背景）。
  后续可加 `sidechaincompress`，但需要 ffmpeg 支持且参数敏感，先不做。

## 5. 配置

```toml
[dub]
mode = "mix"                 # mix | replace
bgm_volume = 0.25            # mix 模式下原声保留比例
max_rate_percent = 35        # 语速上限
source = "translation"       # translation | text
voice_zh = "zh-CN-XiaoxiaoNeural"
voice_en = "en-US-JennyNeural"
```

默认**不自动配音**（多一次联网合成、耗时数分钟），必须显式触发。

## 6. 入口

- **界面**：「统计与导出」面板新增「配音」卡：模式（替换/保留背景音）、背景音比例、
  「开始配音」按钮 → 保存对话框选输出 mp4 → 后台跑全流程 + 进度（合成 x/y → 对齐混音 → 出片）。
- **CLI**：`--dub`（`transcribe`/`run` 均可），配合 `--dub-mode replace|mix`、
  `--dub-bgm 0~1`；产物写在 `--output` 同名 `.mp4`（无 `--output` 时写在输入同目录）。

## 7. 错误与降级

| 场景 | 行为 |
|---|---|
| edge-tts 未安装 | 明确提示 `pip install edge-tts`，不启动流程 |
| 某句合成失败 | 记录该句 index，继续合成其余；最终提示「N 句失败，已按静音处理」 |
| 速率补偿后仍超窗 | 按 4.3 溢出/截断，并在提示里计数 |
| 取消 | 杀 python 子进程，删除临时目录，不产出半成品 mp4 |
| 无译文且 source=translation | 自动回退原文，并在提示里说明 |

## 8. 测试计划

纯函数（`subtitle::dub`）：

- `required_rate_percent`：窗内放得下→None；超窗按比例计算；封顶；
- `plan_placements`：正常/溢出/截断/乱序输入/零长度；
- `mix_track`：不重叠、重叠相加、饱和、总长；
- `voice_for_speaker`：单说话人、多说话人轮换、未知语言回退。

引擎/流程：

- 批量合成参数组装（batch json 形状、rate 格式、临时路径唯一性）；
- 时间轴放置与 WAV 写出（用合成 PCM 走真代码）；
- `replace_video_audio` 已有参数单测（0 替换 / >0 混音）。

## 9. 明确不做（本轮）

- 声音克隆（F5-TTS / CosyVoice / VoxCPM）；
- 逐字 lip-sync / 口型对齐；
- sidechain 动态 ducking；
- 多轨配音（不同语言各一条音轨）。
