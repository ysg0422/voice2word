# 切块跨块上下文：设计与测量方案

> 状态：**设计 + 纯函数就绪，接线待测量后开启**（2026-10-23）。
> 已完成：`chunked_whisper::context_tail`（取末尾若干句、折叠空白、按 char 截尾）
> 与 3 个单测。未完成：把提示注入 whisper 的 `--prompt`，以及 A/B 测量。

---

## 1. 要解决的问题

长音频被切成 N 块并行转写（`plan_chunks` / `run_chunked_parallel`），每块**独立**解码。
后果：

- 块边界处，专名/术语的写法可能前后不一致（前块"张小斐"、后块"张小飞"）；
- 标点风格在块首会重置（前块句末有句号，后块开头又变成无标点连续句）；
- 中文场景更明显：整篇的简体锚点（`DEFAULT_INITIAL_PROMPT`）是全局的，但**上下文**
  （前面在讲什么）每个块都从零开始。

WhisperX 2026 的 "interleaved context"（arXiv:2608.31170）正是为此：把上一批的尾部
文本作为提示喂给下一批。

## 2. 为什么不能直接照搬：本仓库有一条实测反向证据

`src/engines/whisper.rs:964` 记录：

> 这里曾追加 `--carry-initial-prompt`，注释声称「跨段落固化复用 Prefix Prompt」……
> 实测中文 CER 净亏，故移除该参数，只保留 prompt 锚点。

也就是说：**whisper.cpp 的"跨窗口携带提示"在本项目的中文素材上被实测判负**。
跨块提示与它是近亲（都是"用前文当提示"），所以这次必须**先测量再默认开启**，
不能再凭直觉改 ASR 主链路。

## 3. 设计（保留并行度、结果确定）

```
块0 ──(无提示，串行)──► 文本A ──► context_tail(A, N)
                                   │
块1..N ──(提示 = 锚点 + 热词 + context_tail)──► 并行
```

- **只让块 0 先行**：后续块共享**同一个**提示，因此结果**确定**（不依赖调度顺序，
  同一输入两次跑结果一致——这是本项目的硬要求）；
- 代价：串行化一个块 ≈ 总时长的 `1/N`（8 worker、10 块时约 +10% 墙钟）；
- 提示组成：`DEFAULT_INITIAL_PROMPT`（中文简体锚点）+ 热词 + `context_tail`
  （`max_chars` 建议 200，与热词上限同量级，避免挤占 text context）；
- 只在 **whisper** 链路生效：SenseVoice 的 sherpa-onnx 接口没有 prompt 入参。

## 4. 接线点（下一步实施）

| 位置 | 改动 |
|---|---|
| `engines/whisper.rs` | 新增 `context_hint: Mutex<Option<String>>` + `set_context_hint()`；`initial_prompt_args` 旁边加纯函数 `compose_prompt_args(lang, hotwords, hint) -> Vec<String>`（hint 为空时与现状**逐字节相同**） |
| `engines/chunked_whisper.rs` | `transcribe_chunked` 增加 `chunk_context: bool`；为真且块数 > 1 时：先 `run_chunked_parallel(chunks[..1])` → `context_tail` → 设提示 → 再跑 `chunks[1..]`，最后 `optimize_segments` 收口 |
| `core/pipeline.rs` | 把配置位透传进去；关闭时调用路径与现在完全一致（零行为变化） |
| `utils/config.rs` | `pipeline.chunk_context: bool`，**默认 false** |

## 5. 测量方案（决定是否默认开启）

素材：一段 ≥20 分钟、含专名与数字的中文录音（有官方字幕或人工校对稿作参考）。

A/B 对照（其它参数完全一致，各跑 3 次取中位数）：

| 指标 | 采集方式 |
|---|---|
| CER | 参考稿 vs 输出，去掉标点后按字比对 |
| 专名一致率 | 预先列出 K 个专名，统计出现次数中写法正确/一致的比例 |
| 块边界错字率 | 只统计每块前/后 5 秒窗口内的错字 |
| 墙钟 | 同机同线程数 |

判定：**CER 不劣化（≤ +0.3pp）且专名一致率提升**才默认开启；CER 上升就保持默认关闭，
把功能留在配置里给特定素材用。
